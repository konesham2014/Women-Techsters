*What is NPM & package.json ?
NPM stands for Node Package Manager which is the default tool that comes with Node.js.
NPM helps us to install a lot of packages, manage package versions, like update or remove them, run scripts for building, testing, or starting projects and share your own packages with others.

*package.json is a special file used in Node.js and JavaScript projects. It acts like the project’s information file and manager.
package.json is used to store information such as name, version, author and description. It also Lists the packages your project needs which are called dependencies (which tells NPM which libraries to install), contains scripts or commands that we can run and it also helps in sharing  and installing projects like when someone downloads your projects then they don’t need all the packages, they only need the package.json file and run npm install to install the packages that ae listed in the package.json file. 
So package.json helps in keeping track of packages, making installation easy, storing scripts and configuration and allowing people to share the same project without problems.


*What is Vite?
Vite is a modern frontend build tool which is used it to create and develop web apps faster. It helps in starting a new project quickly, fast development server, building an optimized version of your app for production, automatically handling JavaScript, CSS, images, and more, supporting many frameworks like React.
We can use vite if we want a tool that works great with modern frameworks, very fast and has super fast live updates and optimized production.
